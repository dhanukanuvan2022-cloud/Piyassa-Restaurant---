# Piyassa Restaurant Website
A responsive single-page website for Piyassa Restaurant, Dambulla.

## Included
- 17 restaurant/food photos extracted from the supplied PDF and prepared for web display
- Menu content and prices from the two menu pages in the supplied PDF
- No menu-page images used as menu item cards
- Google Maps location embed and directions link
- Opening hours and phone number
- Responsive layout for desktop and mobile

## Run
Open `index.html` in a browser.

## Notes
The menu prices are transcribed from the supplied PDF. If the restaurant changes prices, update `index.html`.
